## LinkedIn

I’ve released ArDali WebMedia v5.2.17, an open-source Linux media workspace focused on bringing local playback, web media, and creative audio tools into one desktop experience.

The project includes music and video playback, a hardware-aware native audio engine, 32-band equalizer and DSP effects, projectM visualization, screen recording, media workflows, localization, and Linux desktop integration. It is distributed under GPL-3.0 with AppImage, DEB, RPM, and AUR installation options, plus release checksums for artifact verification.

This release also strengthens the project’s documentation, packaging consistency, CI permissions, release process, and contributor experience.

Project and downloads: https://github.com/Muhammed-Dali/ArDali-WebMedia
