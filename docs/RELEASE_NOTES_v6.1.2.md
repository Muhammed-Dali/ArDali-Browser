# DaliNira 6.1.2

Released on 24 August 2026.

DaliNira 6.1.2 corrects the installed Linux desktop identity and application
icon.

## Highlights

- Displays the installed application name as `DaliNira` in desktop launchers.
- Installs the verified DaliNira bee-shield icon under the new `dalinira` icon
  identity, preventing legacy user-level `dalinira-browser` icons from
  overriding the packaged icon.
- Publishes the canonical `dalinira` package for both AUR and the DaliNira pacman
  repository.
- Keeps the executable name `dalinira-browser` for command-line and profile
  compatibility.

## Platform status

Linux remains the verified build, test, packaging, and release platform.
