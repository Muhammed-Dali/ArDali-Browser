# ArDali 6.1.2

Released on 24 August 2026.

ArDali 6.1.2 corrects the installed Linux desktop identity and application
icon.

## Highlights

- Displays the installed application name as `ArDali` in desktop launchers.
- Installs the verified ArDali bee-shield icon under the new `ardali` icon
  identity, preventing legacy user-level `ardali-browser` icons from
  overriding the packaged icon.
- Publishes the canonical `ardali` package for both AUR and the ArDali pacman
  repository.
- Keeps the executable name `ardali-browser` for command-line and profile
  compatibility.

## Platform status

Linux remains the verified build, test, packaging, and release platform.
