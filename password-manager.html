Read the detailed notice

Local password vault notice

  • Saved site addresses, usernames, and passwords remain only in the encrypted vault on this device.
  • Records are not sent to an ArDali server or synchronized between devices.
  • The vault is protected by your master password and the operating system's secure key storage.
  • Records cannot be recovered if the master password is forgotten; there is no developer backdoor.
  • No security system provides absolute protection. Malware or a compromised device remains a risk.
  • You can disable the feature at any time. Disabling does not delete the vault; permanent deletion requires separate confirmation.
  • This feature is under security review and is not currently recommended for banking, government, primary email, or cryptocurrency accounts.
