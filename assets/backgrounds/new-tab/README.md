# ArDali new-tab backgrounds

These three original bitmap backgrounds were generated for the ArDali project
with OpenAI's built-in image generation tool on 2026-07-21. They contain no
third-party photographs, logos, text, or remote resources.

- `ardali-flow-blue.png` — dark navy glass-flow composition
- `ardali-aurora-teal.png` — geometric dunes and teal aurora composition
- `ardali-cosmic-violet.png` — violet cosmic-glass composition

They are distributed under the same GPL-3.0-only terms as the ArDali project.
The application loads these files locally and does not contact an image service
at runtime.
