Özellikler ve Şeffaflık

What's new in v5.5.2

  • Native build dependency security remediation
  • Resolved GHSA-r292-9mhp-454m
  • Dependency and release security revalidation

Sürüm ve Güncelleme

  • Uygulama sürümü, Electron ve Chromium sürümü bu pencerede canlı görüntülenir.
  • Otomatik güncelleme bildirimi yoktur; kontrol yalnızca bu penceredeki düğme ile yapılır.
  • Linux + AUR (ardali-bin) kurulumunda güncelleme butonu terminal açıp yay -S ardali-bin komutunu çalıştırır.
  • Güncelleme başlatıldığında çakışma olmaması için uygulama kapanır.

Uygulama Özellikleri

  • Müzik, video, web ve indirme akışını tek arayüzde birleştirir.
  • Modern medya kontrolleri, çoklu dil desteği ve sistem dili algılama içerir.

Web Özellikleri

  • YouTube, Deezer, SoundCloud ve sosyal platformlar için güvenli web medya erişimi sağlar.
  • Oturumlar güvenli web bölmesinde (persist partition) korunur.
  • Gezinme yalnızca izinli ve doğrulanan URL kurallarıyla çalışır.

Password Manager

  • Credentials stay on this device in an AES-256-GCM encrypted vault.
  • A master password and configurable Auto Lock protect the vault.
  • Secure Autofill requires user interaction and exact HTTPS origin matching.

Güvenlik ve Gizlilik

  • Uygulama ayarlarına e-posta/şifre/token gibi hassas bilgiler kaydedilmez.
  • Web görünümü sandbox, izin kontrolü ve alan adı kısıtlarıyla korunur.
  • Harici tarayıcı açma yalnızca geçerli http/https adreslerinde etkinleşir.
  • Chromium Sandbox, Context Isolation, strict CSP, and validated IPC harden application windows.
  • OS Secure Storage protects the local vault's device key.

Ses Efektleri Özellikleri

  • Native C++ DSP altyapısında 32-band EQ, kompresör, limiter, reverb, crossfeed ve ek modüller içerir.
  • Hazır ayarlar, gerçek zamanlı tekerlek kontrolü ve kalıcı efekt ayarları sunar.
  • Çalma sırasında düşük gecikme ve dengeli CPU kullanımı için optimize edilmiştir.

Görselleştirme Özellikleri

  • projectM tabanlı görselleştirme modları ve performans profilleri sunar.
  • FPS, efekt yoğunluğu ve görsel stil ayarları tamamen kullanıcı kontrolündedir.
  • Ses çıkışıyla senkron, düşük gecikmeli canlı görsel geri bildirim üretir.
